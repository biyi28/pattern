## UU Wallet 介绍

UU Wallet 成立于 2022 年，是一家基于区块链技术的数字钱包服务提供商，致力于通过创新的加密支付解决方案为企业和个人用户解决使用场景受限和自由兑换等问题 。该平台获得了美国金融犯罪执法网络（FinCEN）颁发的 MSB（Money Services Business）牌照，标志着其在合规与安全方面达到了较高标准 。

平台的**核心功能**包括安全的加密货币到法币兑换、加密货币预付卡、企业级钱包即服务（WaaS）和 Web3 资产管理 。UU Wallet 支持超过 160 种全球货币，包括 PHP、USD、HKD、KHR、RMB、THB、MYR、VND、SGD、YEN、KRW、AED 以及 USDT 等主要加密货币 。

该平台采用**银行级加密技术**和多重安全保障机制，包括 MPC 钱包分片私钥管理、风险控制预警系统和多轮安全审计，有效防范黑客攻击和异常交易风险 。
